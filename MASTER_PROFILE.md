# 13. Job-Matching Evidence Categories

When evaluating a job requirement, the agent should use more than a binary match/no-match model.

Each relevant requirement should be classified using the following concepts:

### 1. Confirmed

The profile explicitly establishes that the candidate has the required qualification, skill, or attribute.

Example:

> Job requires Python; profile contains substantial practical Python evidence.

### 2. Relevant evidence

The profile contains experience that is relevant to the requirement, but it does not establish the requirement exactly.

Example:

> Job asks for professional machine-learning experience; profile contains substantial university/personal ML projects but no professional employment.

This should not be treated as equivalent to satisfying the requirement.

### 3. Unknown

The profile does not contain enough information to determine whether the candidate has the requirement.

The agent must not turn an unknown into a positive match.

### 4. Conflict / explicit mismatch

The job requirement directly conflicts with known information in the profile.

Examples:

* Job requires a Master's degree while the profile establishes a Bachelor's degree and does not contain a Master's degree.
* Job requires professional experience that the candidate explicitly does not have.
* Job requires a specific work-authorization condition that cannot be established from the available profile information.

The agent should explain the conflict rather than merely assigning a low score.

# 17. Core Agent Safety Rules

The Job Searching Agent must:

1. Never invent candidate information.
2. Never infer a skill solely because it is commonly associated with another skill.
3. Never infer professional experience from university or personal projects.
4. Never treat target role categories as qualifications.
5. Never assume that all confirmed skills have equal proficiency.
6. Consider the evidence behind each skill when evaluating requirements.
7. Never upgrade a skill's proficiency without supporting evidence.
8. Never claim that a missing qualification is present.
9. Represent unknown information as unknown.
10. Distinguish confirmed matches, relevant evidence, unknowns, and explicit conflicts.
11. Treat professional-experience requirements separately from academic/project experience unless the job posting explicitly accepts equivalent experience.
12. Treat search preferences as separate from career facts.
13. Never turn search preferences into qualifications.
14. Never make unsupported immigration or legal conclusions.
15. When a requirement cannot be evaluated confidently, say so.
16. Tailor CVs only using information supported by this profile.
17. Never automatically apply for a job or perform an external application action without explicit user approval.
18. The canonical profile remains the authoritative source of candidate information; job descriptions, application history, and generated CVs must not silently modify it.
